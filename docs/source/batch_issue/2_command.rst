排查问题常用到的命令及参数
===========================
grep搜索查找内容
----------------
对业务或开发提供的线索进行搜索，对问题进行排查，如页面报错，转证单号，客户号等；也可以辅助\
查找配置文件路径等。

文件匹配
^^^^^^^^^^^^^^^^^^
使用grep可以对多个文件同时进行搜索，使用通配符进行目标文件匹配，如：

.. code-block:: bash

    grep 'S51A2_SNGLBSNSFEESUMM2025020100000001' dlbx_app_all.log*

``*``\
号表示所有以dlbx_app_all.log开头的文件都会被grep命令进行关键字搜索;更多通配符说明见\
`通配符文档`_\
或\
``man bash``\
中的\
``Pattern Matching``\
章节。

.. _通配符文档: https://www.gnu.org/software/bash/manual/bash.html#Pattern-Matching

-i 
^^^^^^^^
忽略大小写进行搜索，某些情况下，业务员或开发提供的内容，并不保证是完全正确的，如开发提供的是\
``Cstid``\
，但日志中显示的是\
``CstId``\
，这就会导致无法搜索到相关的内容，加入此参数进行搜索，不管是什么样的大小写，如cstid,CSTID,CsTiD等\
，都可以搜索到。

-R
^^^^^^^^
对所有子目录进行搜索，如业务或开发未提供问题发生的时间，需要跨日期进行多日搜索，加入这个参数则可以对\
所有的日志文件夹进行搜索。

.. hint::

    如果有eventTraceId，则建议在孔明中的应用监控平台中搜索一下，可以用来定位在哪个部署空间中。

    .. image:: ../images/batch_issue/c1.png
        :align: center

    甚至可以点击时间信息，将时间戳转换为人类可读的时间，理方便的查找目标日志：

    .. code-block:: bash

        date -d @$((1790044973452/1000))

    交易信息可以看交易码，用来快速定位到具体日志。

-E
^^^^^^^^
进行正则表达式搜索，常用方法是eventTraceId+交易码快速定位查看某个交易码的报文。

.. code-block:: shell
  
    #.表示任意字符，*表示任意个字符，连起来表示任意个任意字符
    grep -E '108011DLB1738422118805228.*A0381A' dlbx_app_all.log*

正则说明可详见\
`官网`_\
更详细的说明或\
``man grep``\
中的\
``REGULAR EXPRESSIONS``\
章节。

.. _官网: https://www.gnu.org/software/grep/manual/grep.html#Regular-Expressions

-n
^^^^^^^
显示搜索到的行号，方便找到问题日志的具体位置，该行号可配合\
``vim +行号``\
可直接打开并定位到该行号，非常实用。

-l
^^^^^^^^
只显示包含搜索内容的文件名，不显示搜索到的内容。某些场景下，我们有可能并不关心搜索到的内容，只\
关注搜索内容出现在了哪些文件中，如一个客户号只在某几日的分割日志中出现，我们只关心是哪几天，并不\
关心搜索到的客户号，用来排查客户在哪几天发起了交易等。

--color
^^^^^^^^^^^^^^
高亮显示搜索到的内容，方便快速看到指定的搜索内容。容器系统中并没有设置alias，搜索到的内容\
与共它内容用同样颜色显示，内容太多的情况下，肉眼无法即时分辨，加入此参数后，搜索到的内容会\
高亮显示，非常方便。

-A与-B
^^^^^^^^^^
显示搜索到的内容前后指定行数，方便查看上下文信息。A表示after, B表示before。可以非常方便的\
查看搜索到的内容上下文，有助于快速定位问题。

组合使用效果
^^^^^^^^^^^^^^^^^^^^^^

.. code:: bash

    grep -A 10 -B 10 -n -i -R --color 'S51A2_SNGLBSNSFEESUMM2025020100000001' dlbx_app_all.log*

    # -l与部分参数冲突，如-n, --color等，需要单独使用
    grep -l -i -R 'S51A2_SNGLBSNSFEESUMM2025020100000001' dlbx_app_all.log*

.. hint::

    grep的更多参数用法见\
    ``grep --help``\
    ，\
    ``man grep``\
    或\
    `grep官网`_\
    。

    .. _grep官网: https://www.gnu.org/software/grep/manual/grep.html

vim常见用法
---------------------
日常排查问题时，vim的常见用法。

:set encoding=utf8
^^^^^^^^^^^^^^^^^^^^^^^
某些容器的vim默认编码是latin1，进入这些日志查看时，中文内容会显示为乱码内容，此时需要使用\
``:set encoding=utf8``\
设置编码为UTF8，即可正常显示中文内容。

:set hlsearch
^^^^^^^^^^^^^^^^^^^^^^
将搜索到的内容进行高亮显示，有助于快速看到指定的搜索内容。

:set nu
^^^^^^^^^^^^^^^^
显示行号，有些场景下可能会用到。

:set ignorecase
^^^^^^^^^^^^^^^^^^
vim默认是精确搜索，但某些情况下，也有忽略大小写搜索的需求，此时可以\
设置忽略大小写后，进行搜索。

.. hint::

    上述设置可以写入到\
    ``~/.vimrc``\
    中进行自动设置，无须再每次打开文件时手动配置，格式如下：

    .. code:: bash

        set hlsearch
        set encodint=utf8

vim+行号
^^^^^^^^^^^^^^^^
直接打开并定位到该行号，非常实用。使用配合\
``grep -n``\
找到的行号，即可直接打开并定位到该行。

快速翻页
^^^^^^^^^^^^^^^^
需要快速翻阅日志时，可以使用以下的快捷键：

- CTRL+F: 向下翻一页，F(助记Forwards)
- CTRL+B: 向上翻一页，B(助记Backwards)
- CTRL+D: 向下翻半页，D(助记Downwards)
- CTRL+U: 向上翻半页，U(助记Upwards)

查找内容
^^^^^^^^^^^^^^^^

- /: 由上到下查找
- ?: 由下到上查找
- n: 下一个
- N: 上一个

vim中也可以使用正则表达式进行查找，如：

.. code-block:: bash

    /108011DLB1738422118805228.*A0381A

- gg: 定位到文件开头

- shift+g: 定位到文件结尾

.. hint::

    查找问题时，可以判断该交易是否是正常结束：

    - 正常结束的交易，可能进行了多个交易码的处理逻辑，日志量非常多，此时可以采\
      用eventTraceId+交易码的方式，快速定位问题日志，有经验的开发会给出一个交易\
      码进行排查。
    
    - 非正常结束的交易，比如应该进行10个交易码的交易链条，在进行到第8个交易码\
      时失败，此时使用\
      ``?``\
      从文件底部倒着向上搜索，往往会很快定位到失败的日志位置。从上向下查找，\
      会花费很多的时间。

替换内容
^^^^^^^^^^^^^^^^
批量作业有问题，而不能重跑时，需要手动替换作业生成文件中的内容

.. code:: bash

    # 1到100行中将行首替换成#
    1,100s@^@#@g
    # 将所有行首的#替换为空
    %s@^#@@g

u可撤销上一步操作，意为undo。

.. hint::

    可在vim中使用help命令查看更多操作或查看在线\
    `帮助文档`_\
    。

    .. _帮助文档: https://vimhelp.org/

find命令
-----------------
清理文件
^^^^^^^^^^^^^^^^
如系统存储快要满了，需要快速清理一些文件，释放空间：

.. code:: bash

    find . -type f -name "*.log*" -ctime +14 -delete

- -type f: 查找文件，f表示查找类型为文件，d表示查找类型为目录
  
  .. hint::

    更多说明可见\
    `man find`\
    或\
    `find官网`_\
    。

    .. _find官网: https://www.gnu.org/software/findutils/manual/find.html#Type
- -name "\*.log\*": 查找所有包含.log的文件
- -ctime +14: 查找所有创建14天前的文件，ctime意指change time，还有atime(access time)，\
  mtime(modify time)。-表示时间内，+表示时间外，不加只代表指定时间。
- -delete: 删除这些文件

清理文件夹
^^^^^^^^^^^^^^^^
如果系统nas需要清理历史文件：

.. code:: bash

    find . -maxdepth 1 -type d -ctime +30 -exec rm -rf {} \;

- -maxdepth 1: 查找最深的目录层级，表示只查找本级目录
- -exec:执行指定命令，{}表示查找到的内容，如上条命令可以换为ls -l {}
- ``\;``\
  : 表示命令结束，不能省略
